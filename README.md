# Web Development Lab

This repository contains my web development practice work.

## Personal Portfolio Website

The portfolio project is in the `portfolio` folder. It is made with HTML, CSS and JavaScript. The HTML, CSS and JavaScript are kept in separate files.

### Run the website
1. Open the `portfolio` folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. Replace the sample text (name, education, links and project details) with your own information before submitting.

### Project notes
The `P1` to `P13` folders contain short README notes explaining the work covered in each part. The supplied project PDF lists 11 website features; the 13 notes divide the setup and final testing steps as well so the work is easier to follow.
