# P9 – Responsive navbar and card grid using Flexbox

## Aim
Use Flexbox to arrange navigation links and cards, then adapt the layout for smaller screens.

## CSS concepts
- `display: flex`
- `justify-content` and `align-items`
- `gap` and `flex-wrap`
- Media queries

## What I should understand
Flexbox is useful for arranging items along a row or column. The media query changes the layout when the screen becomes narrow.
